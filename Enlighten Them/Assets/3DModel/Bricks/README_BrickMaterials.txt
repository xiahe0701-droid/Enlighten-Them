室内卡通砖材质 / URP 14 / Unity 2022.3
=========================================
01 Cream 奶油白      0.40 x 0.20 米
02 Terracotta 暖陶红 0.36 x 0.18 米
03 Sage 鼠尾草绿     0.40 x 0.20 米
04 MistBlue 雾蓝     0.32 x 0.16 米
05 WarmGrey 暖灰     0.48 x 0.24 米

直接把 .mat 拖到墙体 Renderer。现有 M_Brick 未修改。
无需贴图、无需 UV、无需挂脚本。Unity 1 unit 按 1 米计算。
采用世界坐标三向投影；缩放墙体时砖块保持世界尺寸，数量随墙面积增加。
Brick Width / Height 为含砖缝的重复单元尺寸，可在 Inspector 调整。
Mortar Color 为砖缝颜色；Joint Width 为缝宽；World Pattern Offset 为世界坐标偏移。
支持 URP 光照、阴影、雾、深度和烘焙 Meta pass。

用途限制：
- 适合静态建筑。物体移动、旋转时图案按世界坐标重新对齐，不随物体粘附。
- 倾斜、圆滑曲面处采用三向混合，可能看见图案过渡；不是任意曲面无畸变 UV 展开。
- 砖纹为程序化颜色与柔和边缘明暗，不改变几何轮廓，也不提供真实砖缝凹凸。
- 原 1m grid 使用普通 URP Lit + UV 贴图；本材质为实现缩放保持密度而采用世界坐标。
